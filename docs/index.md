# Overview

This study tests whether a prominent sports-media personality's public picks move the betting market. It focuses on one weekly segment, Colin Cowherd's *Blazin' 5*, in which he names five teams he favors against the point spread, and measures whether the games he picks shift differently from the games he does not, over the same few hours.

The experiment produces a single comparison: the average change in each team's implied chance of winning for the picked games versus the control games, together with a statistical test of whether that difference is distinguishable from chance. It rests on a small set of odds recorded manually on one game weekend, so it is framed as a pilot — a first measurement to establish the method and indicate whether the effect warrants a larger study.
